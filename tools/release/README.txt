Tenchu Z - PC recompilation
===========================

Needs your own Tenchu Z (Xbox 360) disc image (.iso). No game data is included.
Windows 10/11 64-bit, DirectX 12, 4.5 GB free.

Install
-------
1. Run TenchuZ-Setup.exe and choose your disc image.
2. Choose a folder (not inside Program Files).
3. Start Tenchu Z from the Start menu or desktop.

The disc image isn't needed after installing.
Saves are in the "user" folder. Uninstall from Settings > Apps.

Controls
--------
Xbox controller, or keyboard and mouse. Esc opens the menu (display, controls,
audio, online).

  Move         W A S D       Camera       mouse / arrows
  Walk         C             Attack       left mouse
  Strafe       right mouse   Aid          Shift
  Jump         Space         Crouch       Ctrl
  Draw sword   F             Item         E
  Reset view   Q / middle    First person V
  Map          Tab           Pause        Enter
  Items        1-4, mouse wheel

Lasting blood
-------------
Blood stays on you until you swim. Bloody stealth kills stain you too.
Esc > Display > Lasting blood turns it off.

Online (Steam)
--------------
Uses Steam's test app Spacewar (App ID 480): Steam shows you playing "Spacewar".
There is no Tenchu Z server; you play directly with Steam friends.
1. Both players: Steam running, friends on Steam.
2. Start the game. Invite your friend to the lobby from Steam, or wait a few
   seconds to join theirs.
3. Mode Select > System Link: one picks Create Game, the other Search for Game.
"Game Not Found"? Press Esc > Online, click Invite next to your friend, then
search again.
